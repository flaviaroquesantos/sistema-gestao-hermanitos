# sistema-gestao-hermanitos
Sistema de Gestão do Instituto Hermanitos, desenvolvido como MVP para facilitar o cadastro e acompanhamento de pessoas refugiadas e migrantes. A plataforma reúne informações de beneficiários, registros de atendimentos, oportunidades de emprego e encaminhamentos profissionais, promovendo organização, eficiência e inclusão social e profissional.
